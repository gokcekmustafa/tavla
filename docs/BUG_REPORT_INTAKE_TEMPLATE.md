# Bug Report Intake Template

Bu sablon, BQ-002 (ve sonraki bug kayitlari) icin ilk raporu hizla ve standart sekilde toplamaya yardim eder.

## Zorunlu Alanlar

1. Tek cumle bug ozeti
2. Yeniden uretim adimlari (en fazla 5 adim)
3. Beklenen davranis
4. Gerceklesen davranis
5. Etki alani (mod/ekran/rol)
6. Kanit (ekran goruntusu, konsol satiri, zaman damgasi)

## Hizli Kopyala/Sonra Doldur

- Ozet: Bekleniyor
- Adimlar: Bekleniyor
- Beklenen: Bekleniyor
- Gerceklesen: Bekleniyor
- Etki alani: Bekleniyor
- Kanit: Bekleniyor
